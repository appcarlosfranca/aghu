AGHU Notes LOCAL v26 — Primeiro acesso com confetes

NOVO
- Todo NOVO login criado pelo Administrador a partir da v26 recebe uma chuva
  de confetes no primeiro login bem-sucedido.
- A animação acontece somente uma vez para aquela conta.
- Depois do primeiro acesso, o usuário não verá novamente a animação.
- Contas que já existiam antes da v26 são consideradas já apresentadas,
  evitando confete retroativo para usuários antigos.
- Nenhuma biblioteca externa foi adicionada.
- A animação é puramente visual e não interfere em notas, criptografia,
  Google Docs, imagens ou autosalvamento.
- Em dispositivos configurados para "reduzir movimento", a animação é omitida.

TESTE
1. Entre como Administrador.
2. Crie um NOVO login.
3. Saia do Administrador e faça login nessa nova conta.
4. A chuva de confetes aparecerá após a abertura do aplicativo.
5. Saia e entre novamente: não deve aparecer outra vez.
