AGHU Notes LOCAL v25 — Imagens de Consulta Rápida

NOVO:
- Cada paciente/modelo pode ter imagens diretamente dentro da área Nome da lista.
- Clique na nota/paciente e cole um print com Ctrl+V.
- Também é possível usar “＋ imagem” para escolher uma ou várias imagens.
- Arrastar e soltar imagens sobre a área Nome também funciona.
- Miniaturas ficam visíveis imediatamente na listagem para consulta rápida.
- Clique na miniatura para abrir a imagem ampliada.
- É possível remover a imagem pelo X da miniatura.
- No celular, como a lista compacta mostra somente Nome, as imagens permanecem junto do nome.
- As imagens de consulta rápida não são duplicadas na galeria comum do editor.

SEGURANÇA:
- As imagens usam o mesmo armazenamento criptografado AES-GCM já existente na v24.
- Cada imagem fica vinculada ao user_id e ao note_id correspondente.
- A versão continua sem Supabase.

Fluxo recomendado:
1. Abra a lista.
2. Clique em “Luara”, “Modelo admissão”, “Victor Valentin” etc.
3. Copie/print uma imagem em outro local.
4. Volte ao AGHU Notes e pressione Ctrl+V.
5. A miniatura ficará dentro daquela área Nome.
